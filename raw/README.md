# Raw Sources

Immutable source documents. The LLM reads from here but never modifies files in this directory.

| Folder | Contents |
|--------|----------|
| `articles/` | Web clippings, blog posts, news |
| `papers/` | Academic papers, reports, PDFs (as md/txt) |
| `notes/` | Meeting notes, podcast notes, book notes |
| `journals/` | Personal journal entries |
| `media/` | Audio/video transcripts |
| `assets/` | Downloaded images and attachments |
