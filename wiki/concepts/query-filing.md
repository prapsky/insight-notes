# Query Filing

Query filing is a wiki operation. First, answer a question by using the wiki. Then **save a useful combined explanation** as a page in `wiki/queries/` or `wiki/comparisons/`. This lets insights from exploration build up over time, just like knowledge from ingested sources.

## Flow

1. Read the [[../index|index]], then open the relevant pages
2. Combine the information into an answer and cite the sources
3. Save answers that can be reused, then update the index and log

## Principle

Chat is temporary. Filed queries become lasting knowledge. Save an answer when it contains a comparison, a main argument, or a connection that you may want to use again.
