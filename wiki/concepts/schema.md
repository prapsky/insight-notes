# Schema

The configuration document that turns a generic LLM into a **disciplined wiki maintainer**. In this vault: **`.cursorrules`**.

Defines directory layout, page conventions (frontmatter, wikilinks, naming), and workflows for [[concepts/ingest|ingest]], [[concepts/query-filing|query]], [[concepts/wiki-lint|lint]], and schema evolution.

Co-evolve with the human as the domain clarifies — don't expand preemptively.
